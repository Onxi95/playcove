# Static portal with local game modules

Build the portal and all owner-authored game modules as one static TanStack Start site for CDN hosting, with no runtime game backend or player accounts. Each independently authored React game module exports a build-time manifest (including its thumbnail) and play entry point, and imports no TanStack or portal internals; the portal uses the manifest to build catalog, genre, and per-game SEO pages, while each game owns its local nicknames and in-game device-local leaderboard. Adding a game requires rebuilding and redeploying the site; there is no cross-game identity or global leaderboard, and every game route must be explicitly listed or reachable through crawlable links for static prerendering ([TanStack Start static prerendering](https://tanstack.com/start/latest/docs/framework/react/guide/static-prerendering)).
