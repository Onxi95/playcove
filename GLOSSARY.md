# Game Portal

This glossary defines the play modes, player identities, game catalog, and score concepts used by the browser game portal.

## Game catalog

**Standalone game**:
A game that players can start and play on its own, without belonging to a lesson or course.
_Avoid_: Course game

**Game thumbnail**:
A small preview image representing a game in the catalog.
_Avoid_: Miniature

## Play modes

**Local two-player**:
Two people play the same game on one device, sharing its keyboard when the game supports it.
_Avoid_: Online multiplayer

**Solo play**:
One person plays a game independently.
_Avoid_: Single-player mode

## Players

**Local player**:
A player identified within one game on one device by an optional nickname.
_Avoid_: Account

## Scores

**Device-local leaderboard**:
A ranking of one game's scores under local nicknames, shown inside that game and saved on the device.
_Avoid_: Global leaderboard
